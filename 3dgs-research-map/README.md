# 3DGS Research Landscape

用于组会展示的 3D Gaussian Splatting 交互式研究方向图谱。采用 Vite、原生 JavaScript、D3.js 和 SVG，无后端；运行后无需网络即可展示图谱和导出图片。外部论文链接仅在打开论文来源时需要网络。

## 启动

```bash
npm install
npm run dev
```

在终端显示的本地地址打开。构建静态版本：`npm run build`；预览：`npm run preview`。若本机只有 pnpm，可运行 `pnpm install`、`pnpm dev`、`pnpm build`。

## 使用

- 点击方向展开技术分支，点击分支展开论文，点击论文查看右侧详情；再次点击可折叠。
- 左侧支持论文关键词、方向、年份、个人阅读状态筛选，也可以一键展开指定方向、全部展开或折叠。
- 鼠标滚轮缩放、拖拽平移，右上角“适配视图”恢复完整布局。
- 演示模式调用浏览器全屏，`Esc` 退出，`+` / `-` 缩放，方向键平移。
- “导出 PNG”输出完整当前展开树，支持 1920×1080 和 3840×2160，不包含侧栏。导出自动适配全部可见节点，与当前平移缩放无关。
- “我的学习路径”仅表示个人学习计划，并非论文引用关系。

## 更新文献

在 `src/data/papers.js` 中添加一条 `paper(...)` 记录；`primaryCategory` 和 `subcategory` 必须对应 `src/data/categories.js` 中的 ID。每篇论文只能有一个主分类。阅读状态单独存放在 `src/data/reading.js`，避免个人笔记与客观文献信息混在一起。添加文献后同步更新 `sources.md`，并核对正式来源的标题、年份与会议。

当前图谱收录 23 篇种子论文（包含根节点 3DGS）。数量仅指本项目初始文献，不代表领域总论文数。方向分类是研究导航，非文献评价或排名。技术子方向中没有种子论文时不会显示空节点。

## 内容与范围

文献来源见 [sources.md](./sources.md)。核心思想是面向快速浏览的中文概述，具体方法与实验结论以原文为准。当前版本无自动同步文献功能；后续更新需人工维护数据文件。
